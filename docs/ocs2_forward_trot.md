# OCS2 低速前进 trot 初步验证

## 控制目标与实现

在已验证的原地 trot 上增加可选的 `--forward` 模式。仿真时间 8–9 s 平滑加速，9–11 s 以 0.03 m/s 前进，11–12 s 平滑减速，之后保持世界系 x 目标 0.09 m。12 s 后目标前进速度为零，但步态仍是 trot；这还不是从 trot 切回站立的停步测试。OCS2 目标时间表同时包含基座位置、速度以及由 Pinocchio 计算的对应质心动量。生成名义关节状态时，四个名义足端位置与基座一起平移，以免固定足端 IK 将前进目标解释为不断加大的腿部伸展；这些名义足端位置不是 WBC 的地面滑动指令。

每只摆腿在起摆时锁定落脚点。前进落脚点的 x 位移取摆动中点的目标速度乘以 0.70 s 步态周期，恒速阶段约为 0.021 m；竖直方向沿用与当前 OCS2 参数对齐的两段样条。`--forward` 关闭时，目标位移和摆腿 x 位移仍为零。该水平落脚规则是本项目当前的简化实现，尚未包含地形、速度误差或姿态反馈。

## 运行

先按 [原地 trot 记录](ocs2_trot.md) 分别启动 MPC 和 MRT 服务，三个终端均使用 `ROS_DOMAIN_ID=214`。仿真终端运行：

```bash
cd /home/bot/Project/go2_traditional_locomotion
env -u PYTHONPATH ROS_DOMAIN_ID=214 \
  /home/bot/miniconda3/envs/go2_control/bin/python \
  examples/mujoco/ocs2_wbc_standing.py \
  --headless --duration 20 --allow-trot --trot-at 3 --forward \
  --csv artifacts/ocs2_wbc_forward_trot.csv
```

## 2026-10-14 首次无窗口结果

运行完成 20 s、10,000 个 2 ms 仿真步。模式 `15/9/6` 分别占 3137/3449/3414 步。基座最终 x 为 0.09099 m，与最终目标 0.090 m 相差约 +0.99 mm。8–12 s 前进阶段，实测 x 相对目标的 RMSE 为 9.46 mm，最大落后为 13.34 mm；12–20 s 停止后的 RMSE 为 2.06 mm。每步 CSV 同时记录目标 x、MPC 当前参考 x 和 MuJoCo 实测 x。

四脚在计划支撑期间地面法向力大于 1 N 的样本比例均为 100%；摆动目标高度超过 0.07 m 时，中段实际触地样本为零。四脚摆动高度跟踪 RMSE 为 5.75–6.42 mm。最大电机力矩 17.20 Nm，力矩限幅 0 步；基座目标高度 RMSE 为 3.40 mm。已实际触地且连续支撑时，足端中心水平速度 p95 为 4.6–4.9 mm/s，这是球足中心运动的代理量，不能直接当作触地点滑移速度。

完整循环平均墙钟耗时 3.35 ms，10,000 步中有 3609 步超过 2 ms 仿真步长。MPC 仍在仿真循环内同步请求；不同运行的超时步数不能单独证明计算性能变化。带窗口复核后的主观反馈为动作总体良好，仍需逐足水平位移数据做定量确认。完整回归测试为 38 passed、6 warnings；现有自动化测试尚未单独覆盖新的前进命令。运行数据保存在本地 `artifacts/ocs2_wbc_forward_trot.csv` 和同名 JSON，`artifacts/` 不随 Git 提交。

这是一轮以无窗口数据为主、带窗口主观复核的初步验证。MRT 的当前参考 x 与实测 x 很接近，因为控制器反复根据实测状态重新规划；判断命令跟踪应比较目标 x 与实测 x。足端水平目标、实际运动及切回站立已在下文复核；触地点切向速度和转向仍待验证。

## 逐足水平运动复核

在后续同配置的 20 s 无窗口运行中，CSV 增加了四脚世界系 x 与摆腿目标 x。模式 `15/9/6` 分别占 3147/3449/3404 步，最终基座 x 为 0.09077 m，相对 0.090 m 目标误差约 +0.77 mm，力矩限幅仍为 0 步；四脚计划支撑时的地面法向力均大于 1 N，摆动中段没有实际触地。数据见本地 `artifacts/ocs2_wbc_forward_foot_diagnostics.csv` 及同名 JSON。

| 足端 | 8–12 s 摆动 x 跟踪 RMSE | 匀速段单次目标前摆 | 匀速段单次实际前摆 |
| --- | ---: | ---: | ---: |
| FL | 2.92 mm | 21 mm | 16.3–18.2 mm |
| FR | 3.11 mm | 21 mm | 15.6–18.2 mm |
| RL | 2.77 mm | 21 mm | 16.8–18.7 mm |
| RR | 2.67 mm | 21 mm | 17.2–18.6 mm |

上表的单次位移由连续摆动样本的首末值相减，未把加速与减速段的短步长混入匀速统计。所检查匀速摆动的最后一个样本，实际足端 x 比目标落后约 2.3–5.5 mm；随后连续支撑阶段的足端中心 x 位移约 0.5–1.2 mm。数据说明四脚确实交替向前移动，且摆动目标与实际运动量级一致。球形足端可能滚动，支撑期足端中心位移不能直接当作触地点滑移；下一步应计算地面接触点相对速度。

## 从前进 trot 切回四脚站立

仿真增加 `--stop-trot-at` 参数，经同一 ROS 2 步态话题发送 `stance` 模板，模式序列只有 `15`。该指令与 `standing_trot` 一样只发送一次。运行命令：

```bash
cd /home/bot/Project/go2_traditional_locomotion
env -u PYTHONPATH ROS_DOMAIN_ID=214 \
  /home/bot/miniconda3/envs/go2_control/bin/python \
  examples/mujoco/ocs2_wbc_standing.py \
  --headless --duration 20 --allow-trot --trot-at 3 \
  --forward --stop-trot-at 15 \
  --csv artifacts/ocs2_wbc_forward_stop.csv
```

20 s 无窗口运行完成 10,000 步，目标 x 在 12 s 达到 0.09 m、15 s 发送切回站立指令。15 s 后仍会出现 trot 中的短暂模式 `15`，因此不能把首次看到 `15` 当作已经停步。最后一次双足支撑是 16.018 s 的模式 `9`；从 16.020 s 到结束持续为模式 `15`，实际切换比发指令晚约 1.02 s，与当前 MPC 规划窗口的插入方式一致。

16.020 s 时四脚地面法向力约为 FL 48.3 N、FR 54.8 N、RL 53.9 N、RR 45.9 N；此后各脚最小法向力均大于 33 N。站稳后基座 x 到结束只变化约 -0.32 mm，期间 x 的总变化范围约 0.49 mm。最后基座 x 为 0.09183 m，相对目标高约 1.83 mm；高度为 0.28080 m，相对目标高约 0.80 mm。17–20 s 的基座 x 和高度目标 RMSE 分别为 1.90 mm 和 0.47 mm。全程最大电机力矩 17.20 Nm，限幅 0 步。

切换前 16.016 s 的右后脚地面法向力峰值为 102.35 N；同一次切换附近的最大 WBC 动力学和接触加速度残差分别为 7.30e-5 和 1.28e-5。当前结果支持仿真中切回站立并稳定承重，但这些峰值和同步 MPC 请求仍需在实机前评估。数据保存在本地 `artifacts/ocs2_wbc_forward_stop.csv` 及同名 JSON。

## MPC 派生摆腿参考的前进与停步

2026-10-14 使用 `--swing-reference=mpc` 和关节 PD 系数 1 完成 20 s 无窗口运行。WBC 摆腿位置和速度由 MRT 策略生成；本次没有使用 planner 的 `0.70 × forward_velocity` 手工水平落点增量。实现与左转验证见 [转向记录](ocs2_trot_yaw.md)。

```bash
env -u PYTHONPATH ROS_DOMAIN_ID=214 \
  /home/bot/miniconda3/envs/go2_control/bin/python \
  examples/mujoco/ocs2_wbc_standing.py \
  --headless --duration 20 --allow-trot --trot-at 3 --stop-trot-at 15 \
  --forward --joint-pd-scale=1 --swing-reference=mpc \
  --csv artifacts/ocs2_wbc_forward_mpc_swing.csv
```

完成 10,000 步，最终基座 x 为 0.090898 m，相对 0.09 m 目标误差约 +0.898 mm，最终 y 为 0.222 mm、偏航约 0.032°。8–12 s 外部 x 目标跟踪 RMSE 为 9.752 mm，最大误差 14.019 mm；12–20 s RMSE 为 2.250 mm，17–20 s 为 0.767 mm。前进期间仍存在动态滞后。

四脚全程实际向前换步，以下单次位移取完整落在 9–11 s 匀速目标时间段内的连续摆动样本首末 x 差：

| 足端 | 单次实际前摆范围 | 全程实际足端 x 位移 | 8–12 s 有效承重接触切向速度 p95 |
| --- | ---: | ---: | ---: |
| FL | 15.89–18.39 mm | 91.73 mm | 2.27 mm/s |
| FR | 17.04–18.50 mm | 89.10 mm | 1.67 mm/s |
| RL | 17.82–19.04 mm | 90.84 mm | 0.91 mm/s |
| RR | 16.68–18.73 mm | 93.03 mm | 1.14 mm/s |

本次摆动目标来自滚动优化，不再具有固定 21 mm 步长。虽然相对当前策略的摆腿误差较小，策略会根据实测状态重新规划，判断前进能力应以外部机身目标、实际足端位移和接触数据为依据。

15 s 发出停步指令，最后双足支撑样本为 15.998 s，从 16.000 s 起持续模式 15。此后四脚最小地面法向力均超过 31 N；基座 x 到最后记录只变化约 -0.045 mm，期间 x 的总变化范围约 0.343 mm。最终高度为 0.281646 m，相对目标高约 1.646 mm。

四脚计划支撑触地比例均为 100%，摆动中段实际触地样本为零。2–20 s 有效支撑接触切向速度峰值为 FL 34.12、FR 57.21、RL 67.25、RR 29.77 mm/s；FR、RL 峰值均在最终四脚站立切换的 16 s，触地瞬态仍存在，不能宣称无滑移。最大地面法向力为 98.34 N，最大电机力矩 16.37 Nm，力矩限幅 0 步；最大动力学与接触加速度残差分别为 1.11e-5、1.96e-6。

数据为本地 `artifacts/ocs2_wbc_forward_mpc_swing.csv` 和同名 JSON。本轮没有代码改动，未重复完整自动回归。循环平均耗时 3.526 ms，3097/10000 步超过 2 ms；实时执行仍待解决。当前结果支持 MPC 参考路径下的低速前进、逐足实际前摆和停步；该路径右转随后也已完成，见[左右转验证记录](ocs2_trot_yaw.md#mpc-派生摆腿参考左右转验证)。
