# OCS2 原地 trot 偏航转向验证记录

## 目标与实现

`--turn` 在 8–9 s 平滑增加偏航角速度，9–11 s 匀速，11–12 s 平滑减速；12 s 后保持相对初始朝向的目标角度。`--turn-angle-deg` 默认 10°，正值左转、负值右转；已验证的命令为 ±10°，对应峰值角速度幅值 3.33°/s，其他角度尚未验证。完整目标时间表包含旋转后的基座姿态、名义足端布局和对应质心动量。MPC 与摆腿规划使用同一带角度参数的目标函数。

摆腿落点在起摆时锁定。水平落点按摆动中点的目标偏航角速度乘以 0.70 s 步态周期，绕实测基座位置旋转足端相对位置。支撑脚仍由 WBC 接触约束处理。这是简化落脚规则：尚未根据实际偏航角误差修正落点，目标角速度归零后，转向落点增量也归零。

先启动 MPC 和 MRT 服务，见 [原地 trot 记录](ocs2_trot.md)。三个终端均使用 `ROS_DOMAIN_ID=214`：

```bash
  /home/bot/miniconda3/envs/go2_control/bin/python \
  examples/mujoco/ocs2_wbc_standing.py \
  --headless --duration 20 --allow-trot --trot-at 3 --stop-trot-at 15 --turn \
  --csv artifacts/ocs2_wbc_trot_yaw.csv
```

## 左转二维足端运动与接触点速度

增加四脚 y 坐标及摆动目标，与已有 x 坐标组成二维记录。接触诊断通过 `mj_objectVelocity` 读取几何中心的世界系角速度和线速度，用 `v_point = v_geom + omega × (p_contact - p_geom)` 求接触位置处的速度；脚与地面的速度相减后投影到接触坐标系的两个切向轴。只记录求解后法向力大于 1 N 的接触，没有符合条件的接触记为 NaN；同一脚多个接触取最大切向速度。

本次使用 MuJoCo 3.4.0、Euler 积分器。诊断在 `mj_step` 后读取该步的几何、速度和接触求解缓存，对应积分前的运动学状态；该量不代表碰撞响应后的下一步速度。下表只选择计划支撑且有大于 1 N 法向力的有效样本，排除初始 2 s。

### 接触速度分量诊断结果

CSV 新增 `mj_contact_translation_speed_*_mps` 与 `mj_contact_rotation_speed_*_mps`，分别记录几何中心相对线速度和绕几何中心转动的相对速度在接触平面内的幅值。总速度先由两个向量相加，再取切向幅值；两个分量幅值不能直接相加，方向相反时会抵消。若同一脚有多个承重接触点，三项记录均选择总切向速度最大的同一个接触点。没有大于 1 N 法向力的接触时，三项均为 NaN。

| FL | 26.69 mm/s | 19.33 mm/s | 8.11 mm/s | 10.970 s |

FR 峰值主要由几何中心平移项构成，转动项也有贡献。由三个幅值按余弦定理推算，两项切向向量在该时刻夹角约 23.2°，因此大致同向；幅值不是可直接相加的速度百分比。到 15.542 s，FR 总速度降至 14.42 mm/s，平移和转动项分别为 12.03 和 2.47 mm/s；15.560 s 总速度约 1.72 mm/s。

代码检查还发现，WBC 摆腿位置、速度和加速度任务使用锁定摆腿规划器的目标，而 QP 外叠加的关节 PD 使用 MRT 策略的关节位置和速度。当前实现尚未保证这两套参考严格一致。该结构是需要检查的影响因素，现有分量数据尚不能证明它是触地峰值或摆腿末端误差的根因。下一步采用可恢复的关节 PD 补偿单因素对照，比较二维跟踪、触地瞬态、基座姿态和力矩，再决定是否调整参考生成或控制任务。
