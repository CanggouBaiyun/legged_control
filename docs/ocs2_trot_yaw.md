# OCS2 原地 trot 转向：首次无窗口记录

## 目标与实现

`--turn` 在 8–9 s 平滑增加偏航角速度，9–11 s 匀速，11–12 s 平滑减速；12 s 后保持相对初始朝向左转 10° 的目标。峰值角速度为 3.33°/s。完整目标时间表包含旋转后的基座姿态、名义足端布局和对应质心动量。

摆腿落点在起摆时锁定。水平落点按摆动中点的目标偏航角速度乘以 0.70 s 步态周期，绕实测基座位置旋转足端相对位置。支撑脚仍由 WBC 接触约束处理。这是简化落脚规则：尚未根据实际偏航角误差修正落点，目标角速度归零后，转向落点增量也归零。

## 运行

先启动 MPC 和 MRT 服务，见 [原地 trot 记录](ocs2_trot.md)。三个终端均使用 `ROS_DOMAIN_ID=214`：

```bash
env -u PYTHONPATH ROS_DOMAIN_ID=214 \
  /home/bot/miniconda3/envs/go2_control/bin/python \
  examples/mujoco/ocs2_wbc_standing.py \
  --headless --duration 20 --allow-trot --trot-at 3 --stop-trot-at 15 --turn \
  --csv artifacts/ocs2_wbc_trot_yaw.csv
```

## 2026-10-14 首次结果

完成 20 s、10,000 个仿真步，无 WBC 失败中止，力矩限幅为 0 步。**当前偏航目标跟踪未达标，不能记为完成 10° 转向。** CSV 的 `goal_yaw_rad`、`mpc_yaw_rad` 和 `measured_yaw_rad` 分别记录外部目标、当前 MRT 策略参考和 MuJoCo 实测角度。

| 时间 | 目标偏航角 | MPC 当前参考 | 实测偏航角 |
| --- | ---: | ---: | ---: |
| 9 s | 1.667° | 0.039° | 0.039° |
| 10 s | 5.000° | 0.276° | 0.276° |
| 12 s | 10.000° | 1.599° | 1.599° |
| 15 s | 10.000° | 3.464° | 3.464° |
| 最后记录，19.998 s | 10.000° | 4.436° | 4.268° |

8–12 s 实测相对目标的偏航 RMSE 为 5.44°，最大误差 8.57°；16.1–20 s 的目标跟踪 RMSE 为 5.82°。当前 MRT 参考与实测角度很接近，但每 20 ms 根据实测状态重新规划会使策略起点接近当前状态，这不能单独证明完整策略或 WBC 的转向跟踪正确。

15 s 发送停步指令，最后双足支撑样本在 15.998 s，从 16.000 s 起持续四脚支撑。最终基座位置为 [0.000975, -0.003149, 0.282975] m。最大电机力矩 22.52 Nm，最大足端地面法向力 103.17 N。计划支撑时地面法向力大于 1 N 的比例为 FR 99.984%，其余三脚 100%；摆动中段实际触地样本为零。四脚摆动高度 RMSE 为 5.78–6.60 mm；连续实际支撑时足端中心水平速度 p95 为 2.97–4.26 mm/s，不能直接解释为触地点滑移速度。

WBC 平均耗时 0.802 ms，完整循环平均 3.398 ms；1731/10000 步超过 2 ms。MPC 更新仍同步阻塞仿真循环，首次请求包含初始化耗时 619.81 ms。当前结果尚不代表实机实时执行能力。本轮未重新运行自动回归测试。

数据为本地 `artifacts/ocs2_wbc_trot_yaw.csv` 和同名 JSON，原始数据不随 Git 提交。上表偏航指标由 CSV 分析得到，现有 JSON 摘要未包含偏航误差。
